# 删除指令面板

删除指定的指令面板。删除后该面板不再对任何用户或群生效

## 请求

### 基础信息

| 字段 | 值 |
| --- | --- |
| HTTP URL | /v2/panels/{panel_id} |
| HTTP Method | DELETE |
| 接口频率限制 | 10 QPM |

## 路径参数

| 名称 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| panel_id | string | 是 | 面板 ID |

### 请求示例

删除面板

```text
DELETE /v2/panels/p_x8k2x8k2x8k2
```

## 响应

无

## 响应示例

成功

```json
{}
```

### 错误码

| 错误码 | 描述 | 排查建议 |
| --- | --- | --- |
| 40030006 | 指令面板不存在 | 确认 panel_id 是否正确 |
